# PDUAM CSC Students Website

Official website project for the Computer Science Department of Pandit Deendayal Upadhyaya Adarsha Mahavidyalaya, Amjonga.

This project is a static website developed using HTML, CSS, and JavaScript. It provides important information, notices, study resources, gallery updates, and departmental activities for students.

## Features

- Responsive homepage
- Notice and announcement section
- Study material and resource links
- Dynamic gallery section
- Admin panel for content updates
- Local storage based content management
- Modern navigation system
- Multiple department pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## Admin Panel

The project includes a browser based admin panel.

### Admin Features

- Update news ticker
- Manage notifications
- Add or edit resource links
- Manage gallery items
- Dynamic homepage updates

### Admin Files

- admin.html
- admin.css
- admin.js
- site-config.js
